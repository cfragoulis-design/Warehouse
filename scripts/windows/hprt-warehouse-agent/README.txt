SKLAVOUNOS WAREHOUSE HPRT AGENT
Created by Christos Fragoulis

Τι κάνει
--------
Τυπώνει αυτόματα στον HPRT LPQ80 τις δυναμικές ετικέτες που δημιουργούνται
από τη σελίδα Stock / Ετικέτες. Δεν επηρεάζει τον υπάρχοντα Brother Print Agent.

Εγκατάσταση
-----------
1. Βεβαιωθείτε ότι ο HPRT LPQ80 έχει εγκατασταθεί στα Windows και τυπώνει test page.
2. Πατήστε δεξί κλικ στο SETUP.cmd και Run as administrator.
3. Δώστε τη διεύθυνση HTTPS του Warehouse. Αν υπάρχει ένας HPRT στα Windows,
   επιλέγεται αυτόματα· αλλιώς ζητείται το ακριβές όνομά του.
4. Επικολλήστε μία φορά το WORKSHOP agent token. Αποθηκεύεται με Windows DPAPI.
   Σε επόμενη αναβάθμιση το υπάρχον DPAPI token επαναχρησιμοποιείται αυτόματα.

Λειτουργία
----------
- INTERNAL: εσωτερική ιχνηλασιμότητα / δοχεία εργαστηρίου.
- DISTRIBUTION: πλήρης ετικέτα διάθεσης προς εστιατόρια ή πελάτες.
- Το μήκος αλλάζει αυτόματα: 80x72 mm ή 80x120 mm.
- Οι ημέρες συντήρησης και τα σταθερά στοιχεία προέρχονται από το προϊόν.
- Κάθε εργασία κρατά δικό της στιγμιότυπο στοιχείων για ιστορική ιχνηλασιμότητα.

Διαγνωστικά
-----------
Εκτελέστε .\Diagnose-WarehouseHprtAgent.ps1

Το πακέτο δεν περιέχει token.
