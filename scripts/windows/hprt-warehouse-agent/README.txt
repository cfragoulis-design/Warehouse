SKLAVOUNOS WAREHOUSE HPRT AGENT
Created by Christos Fragoulis

Τι κάνει
--------
Τυπώνει αυτόματα στον HPRT LPQ80 τις δυναμικές ετικέτες που δημιουργούνται
από τη σελίδα Stock / Ετικέτες. Δεν επηρεάζει τον υπάρχοντα Brother Print Agent.

Εγκατάσταση
-----------
1. Βεβαιωθείτε ότι ο HPRT LPQ80 έχει εγκατασταθεί στα Windows και τυπώνει test page.
2. Πατήστε δεξί κλικ στο SETUP.cmd και Run as administrator.
3. Δώστε τη διεύθυνση HTTPS του Warehouse. Αν υπάρχει ένας HPRT στα Windows,
   επιλέγεται αυτόματα· αλλιώς ζητείται το ακριβές όνομά του.
4. Επικολλήστε μία φορά το WORKSHOP agent token. Αποθηκεύεται με Windows DPAPI.
   Σε επόμενη αναβάθμιση στο ίδιο Warehouse URL το υπάρχον DPAPI token επαναχρησιμοποιείται αυτόματα.
   Αν αλλάξει περιβάλλον (π.χ. Staging → Production), ζητείται το σωστό token του νέου περιβάλλοντος.

Λειτουργία
----------
- Μία ενιαία πλήρης ετικέτα 50x70 mm για εσωτερική ιχνηλασιμότητα
  και για το προϊόν που ακολουθεί προς εστιατόρια ή πελάτες.
- Ελληνική bitmap εκτύπωση με κεντραρισμένο layout, διατροφικό πίνακα
  (ή ξεχωριστή τεκμηριωμένη εξαίρεση) και οβάλ κωδικό έγκρισης.
- Σε προϊόν που έχει χαρακτηριστεί από διαχειριστή ως «Απλό τεμαχιακό»
  παραλείπονται μόνο τα κενά πεδία συστατικών και αλλεργιογόνων. Προέλευση,
  LOT, ημερομηνίες, συντήρηση και σωστός κωδικός έγκρισης παραμένουν υποχρεωτικά.
- Ο αριθμός έγκρισης προέρχεται από το ρητό προφίλ προϊόντος: διαφορετικός
  για κόκκινο κρέας και διαφορετικός για πουλερικά. Δεν ζητείται καθαρή
  ποσότητα ή extra code.
- Ο renderer δέχεται το προηγούμενο schema 3 και το νέο schema 4, ώστε να
  ολοκληρώνονται με ασφάλεια και εργασίες που υπήρχαν ήδη στην ουρά.
- Οι ημέρες συντήρησης και τα σταθερά στοιχεία προέρχονται από το προϊόν.
- Κάθε εργασία κρατά δικό της στιγμιότυπο στοιχείων για ιστορική ιχνηλασιμότητα.

Παράθυρο κατάστασης
-------------------
Μετά την εγκατάσταση εμφανίζεται στην επιφάνεια εργασίας η συντόμευση
«EFET Print Agent - Status». Δείχνει ζωντανά:
- κατάσταση Agent και εκτυπωτή,
- αυτόματη εκκίνηση και τελευταία επικοινωνία,
- ουρά / τρέχουσα εργασία,
- τελευταία εκτύπωση και σφάλμα,
- ιστορικό των τελευταίων 10 ετικετών.
Περιλαμβάνει Ανανέωση, Επανεκκίνηση Agent και Άνοιγμα διαγνωστικών.

Διαγνωστικά
-----------
Εκτελέστε .\Diagnose-WarehouseHprtAgent.ps1

Το πακέτο δεν περιέχει token.
