RAWLOGIC Transfer Agent 1.0.0
Εγκατάσταση και δοκιμή (χωρίς εγγραφή στο Galaxy)

Τι κάνει
- Διαβάζει ΜΟΝΟ ένα σταθερό SELECT από τη βάση του Galaxy, με τον τρέχοντα
  χρήστη των Windows (Integrated Security) και ApplicationIntent=ReadOnly.
- Στέλνει τη λίστα ειδών προς τα έξω, μόνο όταν αλλάξει.
- Ρωτάει κάθε 10 δευτερόλεπτα αν υπάρχει αρχείο 109 και το γράφει στον φάκελο
  εισερχομένων (προσωρινό αρχείο, έλεγχος sha256, μετά μετονομασία).
- Δεν αντικαθιστά και δεν σβήνει ποτέ έτοιμο αρχείο.
- Ειδοποίηση στην οθόνη και ήχος όταν πέφτει νέο αρχείο.

Τι δεν κάνει
- Δεν γράφει τίποτα στο Galaxy, δεν εκδίδει παραστατικό.
- Δεν αλλάζει τον agent των ετικετών.
- Δεν ανοίγει πόρτα προς τα μέσα και δεν γράφει σε άλλη βάση.
- Ο τρόπος παράδοσης σε αυτή την έκδοση είναι μόνο «file». Το «api» είναι
  για αργότερα και σε αυτή την έκδοση δεν καλεί κανένα API του Galaxy.
  Τα στοιχεία του API, όταν έρθουν, μένουν μόνο σε αυτόν τον υπολογιστή.

Δοκιμή χωρίς αποστολή και χωρίς αρχεία
Άνοιξε PowerShell στον φάκελο του πακέτου και τρέξε:

  powershell -NoProfile -ExecutionPolicy Bypass -File .\TransferAgent.ps1 -DryRun -SqlServer "ΟΝΟΜΑ_SERVER" -SqlDatabase "ΟΝΟΜΑ_ΒΑΣΗΣ"

Θα δεις πόσα είδη βρήκε (κιλά / τεμάχια) και τις γραμμές
«no files written» και «no data sent». Αν το SELECT αποτύχει, σταμάτα.
Μην αλλάξεις το ερώτημα με το χέρι.

Εγκατάσταση (μία φορά, με τον χρήστη που είναι ήδη συνδεδεμένος)
1. Στο Railway, υπηρεσία web, βάλε TRANSFER_AGENT_TOKEN (μακρύ τυχαίο) και,
   όταν το πει ο υπεύθυνος, TRANSFERS_ENABLED=true. Προαιρετικά
   TELEGRAM_TRANSFERS_CHAT_ID, αλλιώς χρησιμοποιείται το υπάρχον Telegram chat.
2. Διπλό κλικ στο SETUP.cmd.
3. Δώσε τη διεύθυνση HTTPS της εφαρμογής, το όνομα του SQL Server, το όνομα
   της βάσης και το token. Το token κρυπτογραφείται με DPAPI και δεν μένει
   σε αρχείο κειμένου.
4. Ο φάκελος, αν δεν τον αλλάξεις, είναι C:\RAWLOGIC\109-INBOX.
   Στην επιφάνεια εργασίας μπαίνει συντόμευση «Ενδοδιακινήσεις 109».
5. Η εργασία «RAWLOGIC Transfer Agent» ξεκινάει στην είσοδο του χρήστη
   (Interactive, Limited). Ο υπολογιστής πρέπει να είναι συνδεδεμένος,
   όπως και με τον agent των ετικετών.

Σταμάτημα
- Άνοιξε το Task Scheduler και σταμάτησε την εργασία «RAWLOGIC Transfer Agent».
- Στην εφαρμογή κλείσε το TRANSFERS_ENABLED. Οι πίνακες μένουν, δεν σβήνουν δεδομένα.

Κατάσταση
  powershell -NoProfile -ExecutionPolicy Bypass -File .\TransferAgent.Status.ps1
