# Personal creator brand asset policy

The only canonical source for Christos Fragoulis creator branding is:

`C:\Users\Onroid\Documents\Sklavounos Operations\assets\personal-brand\final`

Any current or future Sklavounos One surface that displays a personal creator logo,
creator credit, “Christos Fragoulis”, or “Digital Solutions” must reuse the appropriate
approved asset from that directory. Use the horizontal, stacked, mark, dark/light, or
favicon variant according to the documented context. Do not redraw, recolor, stretch,
approximate, or source an older experimental variant.

The Warehouse web UI currently uses the exact `cf-logo-stacked-dark.svg` asset on dark
surfaces. The Windows EFET Agent uses the exact `favicon-64.png` app asset. Copies committed
to the application must remain byte-identical to their canonical source.

This personal identity does not replace legal or product-specific Sklavounos One marks when
those marks are required. It identifies the creator only.
