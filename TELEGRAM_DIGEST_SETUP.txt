Telegram Digest (twice daily via Railway Cron)
--------------------------------------------

1) Set env vars in Railway:
   - TELEGRAM_BOT_TOKEN
   - TELEGRAM_CHAT_ID
   - DIGEST_TOKEN  (choose a random secret string)

2) Add two HTTP POST cron jobs:
   - URL: /internal/telegram-digest-cron
   - Header: X-Digest-Token: <DIGEST_TOKEN>
   - Schedules: 07:00 and 14:20 Europe/Athens

   The token must never be placed in the URL/query string because URLs are
   commonly retained in proxy logs and browser history.

Manual test (admin only):
   POST /internal/telegram-digest
